# Help & feedback page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Help & feedback form off Settings onto a public `/help` page, and link to it from Settings and the marketing footer.

**Architecture:** `/help` is a public App Router page (outside the authenticated `(app)` shell) that reuses the existing `HelpFeedback` mailto form. A server loader reads the session when present and passes optional account props. Signed-out visitors get the same form with browser-only diagnostics. Settings keeps a compact link row. `MarketingFooter` points at `/help` instead of a raw mailto.

**Tech Stack:** Next.js 16 App Router, existing `HelpFeedback` + `lib/support/mailto.ts`, `legalConfig.contactEmail`, custom `lib/i18n` (en/fr/es/ar/zh-Hans), Jest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-24-help-page-design.md`

**Orchestration:** Sonnet 5.5 reviews. Composer 2.5 implements each task. Do not push. Do not change the top nav. No em-dashes (`—`) or en-dashes (`–`) in any new visible string.

function composeBody(message: string, category: SupportCategory, diagnostics?: SupportDiagnostics) {
  const lines = [message.replace(/\r?\n/g, '\r\n')];
  if (diagnostics) {
    lines.push('', '---', `Category: ${CATEGORY_TAGS[category]}`);
    if (diagnostics.email) lines.push(`Account: ${diagnostics.email}`);
    if (diagnostics.userId) lines.push(`User ID: ${diagnostics.userId}`);
    if (diagnostics.plan) lines.push(`Plan: ${diagnostics.plan}`);
    lines.push(
      `Language: ${diagnostics.locale}`,
      `Browser: ${diagnostics.browser}`,
      `Sent: ${diagnostics.sentAt}`,
    );
  }
  return lines.join('\r\n');
}

import { render, screen } from '@/tests/helpers';
import { HelpFeedback } from '@/features/help/components/HelpFeedback';

function renderHelp(
  props?: Partial<React.ComponentProps<typeof HelpFeedback>>,
) {
  return render(
    <>
      <h1 id="help-heading">Help & feedback</h1>
      <HelpFeedback
        supportEmail="support@freeperiod.co.za"
        labelledBy="help-heading"
        accountEmail="teacher@example.com"
        userId="user-123"
        plan="pro"
        {...props}
      />
    </>,
  );
}

function emailLink() {
  return screen.getByRole('link', { name: /write email to support/i });
}

function blockNavigation(link: HTMLElement) {
  link.addEventListener('click', (event) => event.preventDefault());
}

function bodyOf(link: HTMLElement) {
  return new URL(link.getAttribute('href')!).searchParams.get('body') ?? '';
}

describe('HelpFeedback', () => {
  it('renders as a labelled Help & feedback region with category, message and diagnostics', () => {
    renderHelp();
    expect(screen.getByRole('region', { name: /help & feedback/i })).toHaveAttribute('id', 'help');

    expect(screen.getByRole('radio', { name: 'Bug' })).toHaveAttribute('aria-checked', 'true');
    expect(screen.getByLabelText('Message')).toBeInTheDocument();
    expect(screen.getByRole('switch', { name: /include account and browser details/i })).toBeChecked();
    expect(emailLink()).toHaveAttribute('href', 'mailto:support@freeperiod.co.za');
  });

  it('uses guest diagnostics copy when no account is present', () => {
    renderHelp({ accountEmail: undefined, userId: undefined, plan: undefined });
    expect(screen.getByRole('switch', { name: /include browser details/i })).toBeChecked();
    expect(screen.getByText(/adds your browser and language/i)).toBeInTheDocument();
    expect(screen.queryByText(/your email, plan/i)).not.toBeInTheDocument();
  });

  it('blocks an empty message with an inline error and keeps the plain link', async () => {
    const { user } = renderHelp();
    await user.click(emailLink());

    expect(screen.getByRole('alert')).toHaveTextContent(/write a short message first/i);
    expect(screen.getByLabelText('Message')).toHaveAttribute('aria-invalid', 'true');
    expect(screen.getByLabelText('Message')).toHaveFocus();
    expect(emailLink()).toHaveAttribute('href', 'mailto:support@freeperiod.co.za');
    expect(screen.queryByRole('status')).not.toBeInTheDocument();

  it('fills the email with category, message and diagnostics, then shows next steps', async () => {

    await user.type(screen.getByLabelText('Message'), 'Charged twice');
    const link = emailLink();
    blockNavigation(link);
    await user.click(link);

    expect(url.searchParams.get('subject')).toBe('[FreePeriod][Billing][pro] Charged twice');

```tsx
import type { Metadata } from 'next';
import { HelpPageClient } from '@/features/help/components/HelpPageClient';
import { resolveGenerationAccess } from '@/lib/generation/authorize';
import { getMessages } from '@/lib/i18n';
import { readLocaleCookie } from '@/lib/i18n/server';
import { legalConfig } from '@/lib/legal/config';
import { createClient } from '@/lib/supabase/server';
import { getTrialDaysRemaining, isTrialActive } from '@/lib/utils/trial';
import type { Subscription } from '@/types';

export async function generateMetadata(): Promise<Metadata> {
  const locale = await readLocaleCookie();
  const help = getMessages(locale).help;
  return {
    title: help.documentTitle,
    description: help.description,
  };
}

export default async function HelpPage() {
  const supabase = await createClient();
  const {
    data: { user: authUser },
  } = await supabase.auth.getUser();

  if (!authUser) {
    return <HelpPageClient signedIn={false} supportEmail={legalConfig.contactEmail} />;
  }

  const [{ data: profile }, generationAccess, { data: subscriptionRow }] = await Promise.all([
    supabase.from('users').select('email, plan').eq('id', authUser.id).maybeSingle(),
    resolveGenerationAccess(supabase, authUser.id),
    supabase.from('subscriptions').select('*').eq('user_id', authUser.id).maybeSingle(),
  ]);

  const subscription = (subscriptionRow as Subscription | null) ?? null;
  const trialDays =
    subscription && isTrialActive(subscription.trial_end)
      ? getTrialDaysRemaining(subscription.trial_end)
      : null;

  const plan =
    trialDays == null
      ? generationAccess.userPlan
      : `${generationAccess.userPlan} (trial, ${trialDays} days left)`;

  return (
    <HelpPageClient
      signedIn
      supportEmail={legalConfig.contactEmail}
      accountEmail={profile?.email || authUser.email || ''}
      userId={authUser.id}
      plan={plan}
    />
  );
}
```

Do not auto-insert a `users` row here (Settings does that; Help must not). If `resolveGenerationAccess` throws because the profile row is missing, catch and fall back to signed-in props without a plan:

```ts
let plan: string | undefined;
try {
  const generationAccess = await resolveGenerationAccess(supabase, authUser.id);
  plan =
    trialDays == null
      ? generationAccess.userPlan
      : `${generationAccess.userPlan} (trial, ${trialDays} days left)`;
} catch {
  plan = undefined;
}
```

Prefer the try/catch around `resolveGenerationAccess` only; keep the page rendering.

This route lives at `app/help/page.tsx`, not under `app/(app)/`, so it does not get the app Navbar.
